The brain was built and run in the CCAR-F Build 3 notebook. Before any interface was built on top of it, the JavaScript port had to reproduce that run exactly. This page runs the assertions live, against the same scenarios.js the app itself loads.

Assertions

Each row is a figure the notebook printed, checked against what the browser computes now. The last three rows cover the WebMCP surface, where an outside caller can attach free text to a tool call: they prove the verdict does not depend on that text.

Why these figures and not others

The truth here is unusually clean, and it is the reason the whole project can make a hard claim. Every request's correct outcome is decided by arithmetic, not opinion: an amount is above the limit or it is not. So a violation is a fact any reader can check by looking at the row, and the boundary pair settles it, $500.00 correctly paid and $500.01 correctly held. There is no judgement anywhere in the scoring.

If this page fails, the app does not ship. A red banner means the port drifted from the recorded run, and every number in the interface would be describing something that did not happen. Fix the engine, never the interface.
